# Contract freeze ledger

The single source of truth for the freeze state of every proto package. One row per
package. A row flips OPEN → FROZEN only via a **freeze PR** (see
[README.md](README.md#freeze-process)): `.proto` bodies + `baselines/` update + this row
flip + generated fakes, in one PR, with every gating-checklist row cited as checked or
explicitly waived in the decision log (doc 04 §6).

The Stage-0 freeze is **one-shot** (doc 14 preamble): a missed field after the flip is a
v2-package event, not a patch. Nothing is frozen at skeleton time — all rows OPEN, and
the `boundary/` harness's buf-gate test staying RED is the documented correct state.
